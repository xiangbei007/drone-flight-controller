## 测试流程

```

  ↓

  ↓ Int方向正确？
Phase 1 贴地10cm（5分钟）
  ↓ Int收敛？

  ↓ 稳定？
Phase 3 自由1m（10分钟）
  ↓ 漂移<1m？

  ↓ 推动后3-5s归零？

```

## 注意事项

1. **严格按Phase顺序执行**，任何阶段失败不得跳级
2. **Phase 0不可跳过**（坐标系方向错误会在1-2秒失控）
3. **每个Phase保存串口输出**到 `test-result/` 目录
4. **失败数据也要保存**（对调试非常重要）
5. 佩戴护目镜，保持安全距离
