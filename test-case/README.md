## 注意事项

1. **严格按顺序执行**：TC01 → TC02 → TC03
2. **前置测试失败不要跳步**：例如TC02失败，不要执行TC03
3. **失败数据也要保存**：失败数据对调试非常重要
4. **安全第一**：
   - 佩戴护目镜
   - 保持安全距离
   - 首次放飞用系留绳
   - 准备随时断电
5. **详细记录现象**：主观描述文件要详细填写，包括失败情况

## 测试环境要求

- 场地空旷（≥2m×2m）
- 地面有纹理（不能是纯色，光流需要）
- 室内或无风环境
- 光照充足
- 电池电量充足（>3.7V/cell）

## 常见问题

**Q: 如果TC01的Auto-Trim值>5°怎么办？**
A: 说明飞机放置不平，重新调整飞机姿态后重启。

**Q: TC02飞机仍然快速飞走怎么办？**
A: 保存完整串口输出，标注飞走方向，暂停测试等待调试指导。

**Q: TC03光流数据V:0怎么办？**
A: 检查高度是否<1.5m，地面是否有足够纹理，光流传感器是否被遮挡。

**Q: 测试过程中出现异常（如电机满转、翻滚）怎么办？**
A: 立即断电，记录完整现象和串口输出，暂停测试等待调试。
