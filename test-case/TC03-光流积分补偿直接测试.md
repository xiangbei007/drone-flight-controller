# TC03 - 光流积分补偿直接测试（跳过TC02）

## 背景变更

由于飞机底盘有电源线无法平放，自动配平不可用。改为：
- **trim = 0**（不做配平）
- **光流积分自动补偿CG偏移**（飞行中自学习）

## 预期行为

起飞后**前2-3秒会漂移**（因为积分还没建立起来），然后积分逐渐补偿CG偏移，飞机应该**自动稳定下来**。

## 前置条件

- IAR: **Clean + Rebuild All**（重要！）
- 桨叶已安装
- 场地空旷（≥2m×2m），地面有纹理
- 系留绳连接（50cm，防止前几秒漂移时飞走）
- 光照充足

## 安全注意事项

- **必须系留**：前几秒会漂移，系留防止飞走
- 佩戴护目镜
- 准备随时断电
- 45°倾角保护已启用

## 串口输出解读

```
[FLOW] V:1 Vx:12.3 Vy:-5.4 Rt:-1.85 Pt:0.81 Int:-45.2,18.7
       │    │       │       │        │       │         └── Y积分值
       │    │       │       │        │       └── X积分值
       │    │       │       │        └── Pitch目标(°)
       │    │       │       └── Roll目标(°)
       │    │       └── Y光流速度
       │    └── X光流速度
       └── 光流有效
```

### 积分值的含义

积分值 = CG补偿量 / Ki

| Int值 | 对应输出角度(×Ki=0.03) | 含义 |
|-------|------------------------|------|
| ±10 | ±0.3° | 微小CG偏移 |
| ±50 | ±1.5° | 轻度CG偏移 |
| ±100 | ±3.0° | 中度CG偏移 |
| ±200 | ±6.0° | 严重CG偏移 |
| ±250 (饱和) | ±7.5° | 极限补偿 |

**正常收敛过程：**
```
t=0s: Int: 0,0        → 刚起飞，无补偿
t=1s: Int: -30,20     → 正在学习CG偏移
t=3s: Int: -80,55     → 接近收敛
t=5s: Int: -95,60     → 稳定，飞机应该已定住
t=10s: Int: -95,60    → 保持不变 = 补偿成功
```

**异常模式：**
```
Int持续增长到±250 → CG偏移超出补偿能力，飞机仍在漂
Int在正负间跳动  → 振荡，比例增益过高
Int=0始终不变    → 光流无效(V:0)或速度为0（飞机没动？）
```

## 预期结果

### ✅ 通过
- 前2-3秒有初始漂移（正常，积分建立中）
- 5秒后漂移明显减慢
- 10秒后基本稳定（漂移<10cm/10s）
- Int值收敛到某个固定值（不再增长）
- 无剧烈振荡

### ⚠️ 部分通过（需调参）
- 积分收敛慢（>10秒才稳）→ 需增大Ki
- 有轻微振荡 → 需降低Kp或增大Kd
- 稳定但有缓慢漂移 → 需增大Ki或积分限幅

### ❌ 失败
- 持续加速飞走，Int卡在±250 → CG偏移太大或方向错误
- 剧烈振荡 → Kp过大或光流噪声过大
- V:0光流失效 → 地面无纹理或高度过高

## 安全提醒

- **首次测试必须系留！** 积分补偿是否有效未验证
- 如果15秒内飞机仍在加速且Int卡在250，说明方向可能错误，立即断电
- 如果出现剧烈振荡（前后左右快速摆动），立即断电
