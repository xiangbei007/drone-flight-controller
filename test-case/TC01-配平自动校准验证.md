# TC01 - 配平自动校准验证

## 测试目标
验证自动配平校准功能是否正常工作，飞机上电后能否正确记录当前姿态作为零点。

## 前置条件
- 已完成 IAR Clean + Rebuild All
- 飞机放置在**尽量水平**的平面上（桌面、地板）
- 电池电量充足（>3.7V/cell）

## 测试步骤

### 步骤1：上电并记录启动信息
1. 飞机静置在水平面上，不要移动
2. 上电（连接电池）
3. 打开串口监控（波特率115200）
4. 等待约2-3秒，系统初始化完成

### 步骤2：保存启动打印

**必须保存以下内容到文件：`test-result/TC01-启动打印.txt`**

应该看到类似输出：
```
Auto-Trim: Roll=x.xxx, Pitch=x.xxx deg
FlowVelXPID: Kp=0.150, Ki=0.0150, Kd=0.080, Limit=6.0
Flow control: DISABLED
```

### 步骤3：手持观察运行数据

手持飞机（不装桨），保持水平静止约10秒。

**必须保存运行时输出到文件：`test-result/TC01-手持静止.txt`**（至少20行）

应该看到类似输出：
```
[ATT] R:-0.12(0.01) P:0.34(-0.02) Y:123.45 | Gr:2.3 Gp:-1.1
[ATT] R:-0.15(0.04) P:0.31(-0.05) Y:123.50 | Gr:1.8 Gp:-0.5
...
```

### 步骤4：手持倾斜测试

手持飞机（不装桨），向前倾斜约15°保持3秒，然后恢复水平。

**必须保存倾斜过程输出到文件：`test-result/TC01-倾斜测试.txt`**（至少10行）

观察：
- Pitch 绝对值应该增大约15°
- Gp（pitch陀螺仪）应该有明显变化

## 预期结果

### ✅ 通过标准
1. `Auto-Trim` 的 Roll/Pitch 绝对值均 < 5°（说明飞机放置接近水平）
2. 手持静止时，括号内的 R(trim)/P(trim) 在 ±2° 范围内小幅波动
3. 倾斜时，绝对角度和陀螺仪均有明显响应

### ❌ 失败情况
1. `Auto-Trim` 的 Roll 或 Pitch 绝对值 > 5° → 飞机放置不平，重新调整后重启
2. 括号内值持续偏离0（如-3°或+2°）→ 配平校准失败
3. 没有输出或输出乱码 → 串口连接问题

## 保存的文件清单
```
test-result/
  ├── TC01-启动打印.txt        (3-5行，包含Auto-Trim和PID参数)
  ├── TC01-手持静止.txt        (20-30行[ATT]输出)
  └── TC01-倾斜测试.txt        (10-15行[ATT]输出)
```

## 备注
- 如果测试失败，记录失败现象并附上完整串口输出
- 如果飞机异常（如电机突然满转），立即断电并记录现象
