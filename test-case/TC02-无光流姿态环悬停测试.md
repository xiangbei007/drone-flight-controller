# TC02 - 无光流姿态环悬停测试

## 测试目标
验证关闭光流控制后，飞机能否基本稳定悬停（允许缓慢漂移）。这是开启光流控制前的必要前提。

## 前置条件
- TC01 已通过（配平校准正常）
- 光流控制已关闭（`Flow control: DISABLED`）
- 桨叶已安装
- 场地空旷（≥2m×2m），有纹理地面
- 准备系留绳（50cm细线绑飞机底部）

## 安全注意事项
- 佩戴护目镜
- 首次放飞用细线系留，防止飞走
- 保持1.5m安全距离
- 准备随时手动断电
- 45°倾角保护已启用（超过自动关机）
- 测试时间单次 <3 分钟

## 测试步骤

### 步骤1：上电初始化（飞机在水平面上）
1. 飞机放置在水平面上
2. 连接电池上电
3. 等待初始化完成，确认启动打印正常
4. 将飞机移到起飞点

### 步骤2：低空悬停（系留，30cm）
1. 系留绳连接，长度约50cm
2. 起飞至约30cm高度
3. 观察5-10秒
4. 断电降落

**必须保存串口输出到文件：`test-result/TC02-低空悬停.txt`**（尽可能多的数据行）

### 步骤3：高度1m悬停（如步骤2通过）
1. 目标高度1m（FlyControl_height=1.0f）
2. 起飞到1m
3. 观察10-15秒
4. 断电降落

**必须保存串口输出到文件：`test-result/TC02-1m悬停.txt`**

### 步骤4：记录飞行表现

**必须保存到文件：`test-result/TC02-飞行表现.txt`**

记录格式：
```
测试日期: YYYY-MM-DD
测试环境: (室内/室外, 有无风, 地面类型)
测试高度: (30cm / 1m)
系留: (是/否)
悬停时间: (X秒)
飞行表现:
  - 是否能基本悬停: (是/否)
  - 漂移方向: (前/后/左/右/无明显方向)
  - 漂移速度: (快速飞走 / 缓慢漂移 / 基本不动)
  - 估计10秒漂移距离: (XX cm)
  - 是否有振荡: (是/否, 频率快慢)
  - 高度是否稳定: (是/否)
  - 有无异常: (描述)
```

## 预期结果

### ✅ 通过（可进入光流测试）
- 飞机能悬停 5-10 秒不翻滚
- 水平漂移 <50cm/10秒
- 串口 R(trim)/P(trim) 在 ±3° 范围内波动
- 高度基本稳定（±20cm）

### ⚠️ 部分通过（需微调参数）
- 飞机能悬停但缓慢向某方向漂移
- 漂移速度 <10cm/秒
- 串口显示某轴持续偏离（如 R(trim) 持续在 -1°~-2°）

### ❌ 失败
- 飞机快速飞走或翻滚
- 串口显示角度剧烈变化（±10°以上）
- 陀螺仪持续 >30°/s
- 倾角保护触发（45°自动关机）

## 保存的文件清单
```
test-result/
  ├── TC02-低空悬停.txt        (串口输出, 尽可能多的行)
  ├── TC02-1m悬停.txt          (串口输出, 如果步骤2通过)
  └── TC02-飞行表现.txt        (主观描述)
```

## 备注
- 如果步骤2就失败（飞机快速飞走），不要进行步骤3
- 记录失败时飞走的方向，对定位问题很重要
- 如果高度不稳定（上下跳动），单独记录高度相关现象
