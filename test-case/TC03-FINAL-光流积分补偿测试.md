# TC03-FINAL - 光流积分补偿测试（基于三智能体审查优化）

## ⚠️ 重要更新

基于3位资深工程师的审查报告，发现2个关键问题：
1. **🔴 致命风险**：坐标系映射未验证（如果错误，积分会加速漂移）
2. **🔴 严重问题**：积分能力7.5°不够覆盖实测8~8.5°的CG偏移

已修改参数：
- IntLimit: 250 → **280**（积分能力8.4°，覆盖最坏情况+裕量）
- LimitOutput: 8° → **10°**（必须大于积分满载）
- IntThreshold: 50 → **15**（过滤噪声但不阻碍积分）
- 新增条件积分抗饱和（输出饱和时停止累积）

## 前置条件

- **必需硬件**：系留绳**2米**（带弹性段），50cm已证明过短
- IAR: **Clean + Rebuild All**（重要！）
- 桨叶已安装
- 场地空旷（≥3m×3m），地面有明显纹理
- 光照充足

## 安全警告

⚠️ **Phase 0是强制步骤**，不能跳过！如果坐标系错误直接起飞，1-2秒失控。

## Phase 0：坐标系验证（手持，零风险）⭐⭐⭐

### 目的
验证光流X/Y到Roll/Pitch的映射方向正确，积分能**补偿**漂移而非**加剧**漂移。

### 步骤

1. **手持飞机，油门保持0**（电机不转）
2. 上电，等待初始化完成
3. 打开串口监控
4. **人为倾斜飞机Roll轴 +10°**（向右倾斜），保持3-5秒
5. 观察串口输出的 **Int值**

**保存到：`test-result/TC03-Phase0-坐标系验证.txt`**

### 判定标准

```
预期行为：飞机向右倾10° → 光流检测到向右"运动" → Roll积分应为负值
```

| 观察到的Int | 判定 | 下一步 |
|------------|------|--------|
| Int < -20（负值） | ✅ **通过** | 继续Phase 1 |
| Int ≈ 0 | ⚠️ 光流无效 | 检查地面纹理、光流传感器 |
| Int > +20（正值） | 🔴 **致命错误** | 立即停止，修正坐标系代码 |

**如果Phase 0失败（积分方向错误）：**
- 不要起飞！
- 检查代码中光流到姿态的符号映射
- 可能需要反转 `roll_target = -FlowVelXPID.output` 或类似

## Phase 1：10cm贴地悬停（低风险验证）⭐⭐

### 目的
低高度验证积分能否收敛，避免高空失控。

### 步骤

1. 装桨，系留绳连接（2米）
2. 起飞到**10cm高度**（刚离地）
3. 悬停10-15秒
4. 观察积分值变化和飞机稳定性

**保存到：`test-result/TC03-Phase1-贴地悬停.txt`**

### 预期行为

```
t=0-2s:  初始漂移，Int快速增长（如 0 → -50 → -100）
t=3-5s:  漂移减缓，Int增速降低（-100 → -150 → -180）
t=5-10s: 基本稳定，Int收敛到某固定值（如 -185 ± 10）
```

### 判定标准

| 观察 | 判定 | 说明 |
|------|------|------|
| Int收敛到 -50~-150，飞机稳定 | ✅ 通过 | CG偏移中等，继续Phase 2 |
| Int收敛到 -200~-280，飞机稳定 | ⚠️ 勉强通过 | CG偏移严重但在能力范围内 |
| Int卡在 ±280，飞机仍漂移 | 🔴 失败 | CG偏移>8.4°，超出补偿能力 |
| 剧烈振荡（前后左右快速摆） | 🔴 失败 | PID参数过激或光流噪声过大 |

**失败应对：**
- Int饱和仍漂：增大IntLimit到350（能力10.5°）
- 振荡：降低Ki到0.02或Kp到0.10

## Phase 2：50cm系留悬停（典型高度）⭐

### 步骤

1. Phase 1通过后，提升到50cm高度
2. 系留绳2米（确保有足够缓冲）
3. 悬停15-20秒

**保存到：`test-result/TC03-Phase2-50cm系留.txt`**

### 观察重点

- 系留绳是否拉紧？（拉紧=漂移>2m，积分不足）
- Int值是否与Phase 1接近？（应该相似，因为CG偏移不变）
- 高度稳定性

## Phase 3：1m自由悬停（最终验证）⭐

### 前置条件
Phase 2通过，Int值稳定在<250，无剧烈振荡。

### 步骤

1. 解除系留绳
2. 起飞到1m高度
3. 悬停20秒
4. 观察漂移距离

**保存到：`test-result/TC03-Phase3-自由悬停.txt`**

### 通过标准

- 20秒漂移 < 1米
- 无剧烈振荡
- Int值收敛且稳定

## Phase 4：抗扰测试（阶段2核心功能）⭐⭐⭐

### 步骤

1. 1m悬停稳定后
2. 轻推飞机（向前/后/左/右）
3. 松手后观察是否自动减速归零

**保存到：`test-result/TC03-Phase4-抗扰测试.txt`**

### 阶段2通过标准

- 推动后3-5秒减速到接近静止
- 能回到原位或偏离 < 50cm
- Vx/Vy从推动时的±50回落到±5

## 串口输出解读

```
[FLOW] V:1 Vx:12.3 Vy:-5.4 Rt:-1.85 Pt:0.81 Int:-185.2,78.7
                                              └── 关键：积分值
```

### 积分值的含义

| Int值 | 对应输出(×0.03) | CG偏移估计 | 状态 |
|-------|----------------|-----------|------|
| ±10-50 | ±0.3-1.5° | 轻微 | ✅ 健康 |
| ±50-150 | ±1.5-4.5° | 中等 | ✅ 正常 |
| ±150-250 | ±4.5-7.5° | 严重 | ⚠️ 接近极限 |
| ±250-280 | ±7.5-8.4° | 极严重 | ⚠️ 极限补偿 |
| ±280（饱和） | ±8.4°（限幅） | **超出能力** | 🔴 失败 |

### 正常收敛曲线

```
Phase 1 (10cm):
t=0s:  Int: 0, 0          Vx: 15, Vy: -20   (初始漂移)
t=2s:  Int: -80, 45       Vx: 8, Vy: -10    (快速收敛)
t=5s:  Int: -145, 68      Vx: 2, Vy: -3     (接近稳定)
t=10s: Int: -158, 72      Vx: 0.5, Vy: -1   (完全稳定)

Phase 2/3/4: Int值应保持在 -158±20 范围内
```

```
Phase 0（手持验证）
  ├─ Int方向错误 → 🔴 不起飞，修正代码

  ├─ 10s后Int收敛且<250 → Phase 2

  ├─ 推动后3-5s归零 → ✅ 阶段2通过！
```

## 失败应急预案

| 失败场景 | Phase | 诊断 | 立即操作 | 修复方案 |
|---------|-------|------|---------|---------|
| Int方向错 | 0 | 积分与倾斜同向 | 断电，不起飞 | 反转roll_target符号 |
| Int=280饱和 | 1/2 | CG>8.4° | 断电 | IntLimit += 70 |
| 剧烈振荡 | 1/2 | PID过激/噪声 | 断电 | Ki /= 2 或 Kp -= 0.05 |
| 系留拉紧摆动 | 2 | 系留绳约束 | 继续观察 | 延长系留绳到3m |
| 光流V:0 | 任何 | 传感器失效 | 断电 | 检查地面/高度/遮挡 |

## 总结

**本次测试的核心改进：**
1. ✅ Phase 0强制坐标系验证（防止致命错误）
