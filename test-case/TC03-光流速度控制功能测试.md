# TC03 - 光流速度控制功能测试（仅在TC02通过后执行）

## 测试目标
验证光流速度控制能否让飞机抵抗水平漂移，实现「推动后自动减速归零」的能力。

## 前置条件
- **TC02 必须已通过**（飞机无光流时能基本悬停）
- 需要修改代码：`flow_ctrl_enable = 1` （重新编译烧录）
- 场地空旷，地面有纹理（不能是纯色）
- 光照充足（光流传感器需要）
- 高度 <1.5m（光流有效范围）

## 代码修改

在 `main_cm7_0.c` 中修改：
```c
static uint8_t flow_ctrl_enable = 1;   // 改为1，开启光流
```

重新编译烧录后，启动打印应显示：
```
Flow control: ENABLED
```

## 测试步骤

### 步骤1：静止悬停（验证光流不干扰）

1. 飞机放飞到50cm高度
2. 让飞机自然悬停10秒，**不要推动**
3. 观察是否比TC02更稳定

**保存串口输出到：`test-result/TC03-静止悬停.txt`**

### 步骤2：抗扰测试（核心功能）

1. 飞机悬停在50cm高度
2. 用手轻推飞机（向前/后/左/右）
3. 推动后立即松手，观察飞机是否自动减速归零
4. 每个方向测试1次

**保存串口输出到：`test-result/TC03-抗扰测试.txt`**

记录推动时刻，便于分析数据。例如：
```
// 第5秒时向右推动
[FLOW] V:1 Vx:0.2 Vy:-0.5 Rt:-0.03 Pt:0.08 Gx:1.2 Gy:-0.8
[FLOW] V:1 Vx:45.3 Vy:-1.2 Rt:-6.00 Pt:0.18 Gx:-3.5 Gy:1.1   ← 推动瞬间
[FLOW] V:1 Vx:32.1 Vy:0.8 Rt:-4.82 Pt:-0.12 Gx:-1.8 Gy:0.5   ← 松手后
[FLOW] V:1 Vx:12.4 Vy:0.3 Rt:-1.86 Pt:-0.05 Gx:0.3 Gy:0.2    ← 减速中
[FLOW] V:1 Vx:1.8 Vy:-0.1 Rt:-0.27 Pt:0.02 Gx:0.8 Gy:-0.3    ← 接近静止
```

## 预期结果

### ✅ 通过阶段2
- 静止悬停比TC02更稳定（漂移减少50%以上）
- 推动后1-3秒自动减速到接近静止
- 能回到原位或偏离 <30cm
- 无明显振荡
- 串口显示 Vx/Vy 在 ±5 范围内波动
- 串口显示 Rt/Pt 有响应（非饱和）

### ⚠️ 部分有效（需微调参数）
- 有减速效果但不够快
- 串口显示 Rt/Pt 频繁饱和在 ±6°
- 有轻微振荡

### ❌ 失败（问题仍未解决）
- 推动后不减速，继续加速飞走
- 出现振荡，比无光流时更不稳定
- 串口显示 Vx/Vy 持续增大
- 串口显示光流 V:0（光流数据无效）

## 串口输出解读

### [FLOW] 格式说明
```
[FLOW] V:1 Vx:12.3 Vy:-5.4 Rt:-1.85 Pt:0.81 Gx:2.1 Gy:-1.3
       │    │       │       │        │       │       └── Pitch陀螺仪(°/s)
       │    │       │       │        │       └── Roll陀螺仪(°/s)
       │    │       │       │        └── Pitch目标角度(°) = -FlowVelYPID.output
       │    │       │       └── Roll目标角度(°) = FlowVelXPID.output
       │    │       └── Y光流速度(像素/帧)，正=向前
       │    └── X光流速度(像素/帧)，正=向右
       └── 光流有效(1=有效, 0=无效)
```

### 正常工作特征
- V:1 持续
- Vx/Vy 在 ±5 范围内小幅波动
- Rt/Pt 在 ±2° 范围内响应
- 推动后 Vx/Vy 增大，Rt/Pt 相应增大（同向），然后一起衰减

### 异常模式
- V:0 持续 → 光流失效（高度过高/地面无纹理/遮挡）
- Vx/Vy 持续递增 → 光流控制无效，飞机失控
- Rt/Pt 卡在 ±6.0 → PID输出饱和，需增大限幅或Kp
- Vx/Vy 快速切换正负 → 振荡，需降低增益或增强滤波

## 备注
- 如果TC02未通过，不要执行TC03（光流控制依赖稳定的姿态环）
- 如果光流数据经常V:0，检查地面纹理和高度
- 如果出现振荡，立即断电，降低光流PID参数后重试
