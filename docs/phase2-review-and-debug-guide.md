## B. 测试问题根因分析

### 问题1：X轴增益异常低（实测0.01 vs 代码0.15）

**数据证据：**

| 测试文件 | 样本 | 实测增益 |
|----------|------|----------|
| 有限辐手持 | Vx:114.1→Rt:-1.13 | 0.0099 |
| 有限辐手持 | Vx:-51.9→Rt:0.53 | 0.0102 |
| 取消限辐手持 | Vx:-137.6→Rt:1.39 | 0.0101 |
| 取消限辐手持 | Vx:142.0→Rt:-1.40 | 0.0099 |

X轴增益始终为0.01，而Y轴正常（0.14-0.15）。

**根因：IAR增量编译问题**

最可能原因是 PID.c 修改后，IAR未重新编译该文件，链接时使用了旧的.o文件。FlowVelXPID的Kp可能仍然是某个旧版本的值（如0.01）。

**验证方法：** 启动诊断打印：
```
FlowVelXPID: Kp=0.150, Ki=0.0150, Kd=0.080, Limit=6.0   ← 正确
FlowVelXPID: Kp=0.010, ...                                 ← IAR编译缓存问题确认
```

### 问题2：手持振荡

**正反馈环路：**
```
电机转动 → 机身高频振动 → 光流传感器误读 → 速度PID输出 → 姿态目标变化
→ 角度/角速度PID响应 → 电机差速输出 → 更多振动
```

**修复措施：**
- 陀螺仪补偿（系数0.3，减去旋转引起的假位移）
- 低通滤波（alpha=0.3）

### 问题3：放飞后单向加速

**多因素叠加：**
1. X轴增益bug为主因 — 侧向只有0.01增益，几乎无纠正能力
2. 积分配置失效 — 旧Ki×LimitIntegral=0.001×3.0=0.003°（等于无积分）
3. 输出限幅±4°制动力不足 — 大速度时无法快速减速

### D.2 测试优先级和顺序

| 优先级 | 测试项 | 方法 | 通过标准 |
|--------|--------|------|----------|
| **P0** | 验证X轴增益 | 开机读串口启动打印 | FlowVelXPID: Kp=0.150 |
| **P1** | 溢出修复验证 | 不装桨，倾斜飞机>15°观察电机 | 电机不会突然满转 |
| **P2** | 光流数据质量 | 手持悬停读取[FLOW]输出 | Vx/Vy在±5内波动，Rt/Vx≈0.15 |
| **P3** | 陀螺仪补偿效果 | 手持原地旋转飞机 | Gx/Gy有变化但Vx/Vy不随之大幅变化 |

| **P6** | 抗扰恢复 | 轻推飞机后释放 | 3秒内恢复静止 |

### D.3 串口输出解读

**运行时[FLOW]输出格式：**
```
[FLOW] V:1 Vx:0.3 Vy:-0.2 Rt:-0.05 Pt:0.03 Gx:2.1 Gy:-1.5
       │    │       │       │        │       │       └── pitch陀螺仪(°/s)
       │    │       │       │        │       └── roll陀螺仪(°/s)
       │    │       │       │        └── pitch目标角度(°) = -FlowVelYPID.output
       │    │       │       └── roll目标角度(°) = FlowVelXPID.output
       │    │       └── 滤波后Y光流速度(像素/帧)
       │    └── 滤波后X光流速度(像素/帧)
       └── 光流有效(1=有效,0=无效)
```

**正常悬停特征：**
- V:1 持续
- Vx/Vy: 在±1.0范围内小幅波动，均值接近0
- Rt/Pt: 在±0.5°范围内波动
- Gx/Gy: 在±5°/s范围内

**异常模式识别：**

| 串口模式 | 诊断 |
|----------|------|
| `V:0` 持续 | 光流传感器故障/遮挡/高度过高 |
| `Vx`持续正且递增，`Rt`卡在±6.0 | 输出饱和→单向加速（增益不足或限幅不够） |
| `Vx`在±5间快速切换 | 正反馈振荡（补偿不足或PID过激） |
| `Rt`有响应但`Vx`不收敛 | 内环（角度/角速度）跟踪不良 |
| `Gx`>20°/s持续 | 机械振动过大或姿态失控 |
| `Rt/Vx`≈0.01而非0.15 | X轴增益bug未修复 |

### D.4 调试决策树

#### 场景1：X轴增益仍然低

```
IF 启动打印 Kp ≠ 0.150
├── THEN: IAR增量编译问题确认
│   ├── 执行: Project → Clean → Rebuild All
│   └── 验证: 重新烧录后再次检查启动打印
│
IF 启动打印 Kp = 0.150 但运行时 Rt/Vx ≈ 0.01
├── THEN: 运行时被覆盖
├── 在main()初始化后强制赋值:
│   FlowVelXPID.kp = 0.15f;
│   FlowVelXPID.ki = 0.015f;
│   FlowVelXPID.kd = 0.08f;
└── 检查是否有其他代码修改FlowVelXPID
```

#### 场景2：仍然振荡

```
IF 手持时Vx/Vy振幅 > ±5
├── 判断振荡频率:
│   ├── IF 高频(>5Hz) — 电机振动耦合
│   │   ├── 降低 FLOW_LPF_ALPHA: 0.3 → 0.15
│   │   ├── 提升 FLOW_GYRO_COMP: 0.3 → 0.5
│   │   └── 物理减振（光流传感器加海绵垫）
│   └── IF 低频(0.5~2Hz) — PID过激
│       ├── 降低 FlowVelPID.kp: 0.15 → 0.08
│       ├── 增加 FlowVelPID.kd: 0.08 → 0.12
│       └── 降低 FlowVelPID.alpha: 0.6 → 0.4
```

#### 场景3：仍然单向飘移

```
IF 放飞后持续向一个方向加速
├── IF Rt卡在±6.0（饱和）
│   ├── 提升 LimitOutput: ±6° → ±8°
│   └── 提升 Kp: 0.15 → 0.25
├── IF Rt未饱和但飞机仍漂移
│   ├── 配平值不准确
│   ├── 调整配平: 静止悬停时记录平均roll/pitch偏移
│   └── 修改 +2.783/+3.17 为实测值
└── IF V:0（光流丢失）
    └── 检查高度是否超出光流工作范围（建议<1.5m）
```

### D.5 安全注意事项

| 类别 | 措施 |
|------|------|
| **人身安全** | 测试时佩戴护目镜；飞机用细线系留（50cm）防止飞走；保持1.5m距离 |
| **电机安全** | 首次上电先验证串口打印，确认无异常再装桨叶；测试溢出修复时先不装桨 |
| **断电机制** | 代码已有45°倾角保护自动关机；另备手动断电方案 |
| **电池** | 电压低于3.5V/cell立即降落；测试时间单次<3分钟 |
| **场地** | 室内净空2m×2m×2m以上；地面铺纹理材料（光流需要纹理） |
| **渐进测试** | P0-P3全部在手持/系留状态完成，P4/P5再自由飞行 |
