# test-result 测试结果目录

请将测试结果文件按照 test-case 中指定的文件名保存到此目录。

## 文件命名规范

每个测试用例（TC01/TC02/TC03）需要保存以下文件：

### TC01 - 配平自动校准验证
```
TC01-启动打印.txt          串口启动信息（3-5行）
TC01-手持静止.txt          手持静止时的[ATT]输出（≥20行）
TC01-倾斜测试.txt          手持倾斜时的[ATT]输出（≥10行）
```

### TC02 - 无光流姿态环悬停测试
```
TC02-低空悬停.txt          30cm悬停串口输出
TC02-1m悬停.txt            1m悬停串口输出（TC02步骤2通过后才做）
TC02-飞行表现.txt          主观描述（按模板填写）
```

### TC03 - 光流速度控制功能测试（TC02通过后才做）
```
TC03-静止悬停.txt          光流开启后静止悬停串口输出（≥20行）
TC03-抗扰测试.txt          推动测试串口输出（包含推动时刻标注）
TC03-功能评价.txt          主观评价（按模板填写）
```

## 注意事项

1. 串口输出直接复制粘贴保存为.txt文件
2. 主观描述文件按照test-case中给出的模板填写
3. 如果测试失败，同样保存数据（失败数据对调试非常重要）
4. 文件编码统一使用 UTF-8
5. 按 TC01 → TC02 → TC03 顺序执行，前置测试失败不要跳步
